About the analysis

A performance lens, not a prediction of race-day conditions.

The dashboard mirrors the core tools in the Birkie Stats Companion app: searchable results, wave comparisons, performance context, field statistics, and projected wave placement.

All calculations happen in your browser from an archived 2022–2026 results dataset. This independent project is not affiliated with the American Birkebeiner Ski Foundation.
